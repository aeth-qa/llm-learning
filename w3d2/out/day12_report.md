### Полные ответы

**A (кратко, формально, без кода)** (слов: 24):

```
Используйте оператор in: "ключ in словарь" возвращает True или False. Для получения значения с проверкой удобен метод словаря get с указанием значения по умолчанию.

**B (подробно, неформально, с кодом)** (слов: 220):

```
Коротко: через оператор `in`.

Самый частый способ — проверить наличие ключа оператором `in`:

```python
d = {"a": 1, "b": 2}

if "a" in d:
    print("ключ есть")

if "c" not in d:
    print("ключа нет")
```

Пара нюансов и альтернатив:

```python
# 1. in — проверяет именно ключи (не значения)
"a" in d          # True
1 in d            # False (1 — это значение, не ключ)

# 2. Метод .get() — если тебе нужно и проверить, и достать значение
value = d.get("a")            # 1
value = d.get("c")            # None (по умолчанию)
value = d.get("c", "нет")     # "нет" — своё значение по умолчанию

# 3. keys() — работает, но избыточно
"a" in d.keys()   # True, но лучше просто "a" in d

# 4. try/except KeyError — когда ключ почти всегда есть,
#    а отсутствие — исключение
try:
    v = d["a"]
except KeyError:
    v = None
```

Что выбрать:
- просто проверить наличие — `in`;
- проверить и сразу взять значение с дефолтом — `get()`;
- ключ обязан быть, иначе ошибка — обычный `d[key]` с обработкой `KeyError`.

Небольшой пример «в жизни» — счётчик слов:

```python
counts = {}
for word in ["кот", "пёс", "кот"]:
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1

# или короче:
counts = {}
for word in ["кот", "пёс", "кот"]:
    counts[word] = counts.get(word, 0) + 1
```

**C (сбалансированно, дружелюбно)** (слов: 66):

```
Несколько способов:

- Через in (самый частый): if "key" in d: ...
  Проверяет ключи, быстро, без исключений.

- Через get, если нужно значение по умолчанию: value = d.get("key", default)

- Через try/except KeyError: value = d["key"] — если ключа нет, ловишь исключение. Обычно оправдано, когда ключ в норме есть, а отсутствие — исключительная ситуация.

Коротко: для простой проверки — in, для значения с фолбэком — get.
```
